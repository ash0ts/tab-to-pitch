# Music teacher: qualification is separate from enablement

The teacher uses bounded musical tools and a separate factual review. Experimental access is not a claim of qualification. The app displays the status reported by the configured backend; unavailable inference falls back to authored tools.

The historical teacher campaign retained failed actor/judge qualifications. Unexecuted suite cases are not successes. A successful fallback is not an actor success. See the private research project for the relevant campaign and its original failure records.

- [Private Agent Lens](https://forge.coreweave.com/agent-lens/wandb/tab-to-pitch-public-data-research)
- [Private Weave evaluations](https://forge.coreweave.com/wandb/wandb/tab-to-pitch-public-data-research/weave/evaluations)

The new practice-stage-v1 suite tests presentation integrity locally. No new teacher inference, evaluator qualification or human learning study has been run for this studio change. The shared historical inference allowance has not been increased.
