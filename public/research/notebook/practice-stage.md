# Practice stage: presentation integrity

Protocol: practice-stage-v1, frozen 4 November 2026. This change tests task navigation, answer masking, first-response evidence, assistance, scoring, source changes and playback-driven graphics.

Cases cover changed goals, help during a challenge, repeated errors, unassessed audio, exposed transfer material, unsupported playing claims, duplicate events and stale attempts. Scoring is deterministic and references existing attempts. Animation never supplies evidence.

Local tests run without new model inference. The Forge teacher comparison, human usability study and learner study remain unexecuted. No new training run or inference allowance was created. Experimental guitar input is excluded from ranked challenges.

Later studies should report independent recall after a delay, transfer to a new musical context, actual playing and voluntary return separately.
