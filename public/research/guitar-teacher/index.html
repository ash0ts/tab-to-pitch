Can the teacher turn a request into something you can play?

A controlled comparison on passages drawn from recorded guitar. We tested the current teacher, a revised prompt, and the existing local policy. We checked the actual fretboard highlights and accompaniment variations they returned.

This tests musical tool use and reliability. It does not test whether the model can hear a recording, teach well, or improve a learner’s playing.

What the data establishes

Recorded music, authored requests

GuitarSet contains acoustic guitar recordings and string-specific note annotations. We use intended lead-sheet chords for the requested accompaniment and a stable annotated note to anchor each chord-role task. Performed chord labels are partly inferred from the note annotations; they are not independent human chord judgments.

Six development recordings use performers 00/01 and progression family 1. The 36 evaluation recordings use performers 02/03/04 and families 2/3, with six recordings in each performer/family cell. All are accompaniment recordings. Three publisher-reported annotation errors and the earlier live-coach cohort are excluded.

Development contains major-triad passages; evaluation also contains minor, dominant-seventh and half-diminished harmony. That domain shift is part of this split. No recording audio was sent to the teacher. Questions and learner history are authored, not real learner responses.

Independent checks, explicit limits

The scorer uses its own note arithmetic and chord formula tables. It checks every highlighted position; for variations it checks chord tones, required degrees, strings, frets, voice count, span and harmonic timing. Mutation tests corrupt these fields deliberately.

The target is a valid requested artifact, not agreement with one fingering. The deterministic engine’s control establishes whether the requested artifact is available. Protocol, split membership, prompts, source and scoring were frozen before evaluation.

The corpus supported earlier voicing research. “Held out” means disjoint from this prompt development, not globally unseen. Model pretraining overlap is unknown. Inferred fret locations do not establish the recorded player’s hand technique.
