# Guitar homework media

Captured from the integrated app in an isolated Playwright Chromium browser on November 4, 2026. The original studies and illustrated studio assets are included in this repository. No personal score, commercial recording, user history or live cloud response appears here.

- `walkthrough.mp4`: continuous UI walkthrough at original speed, without an audio track.
- `preview.gif`: the same capture at 1.67× speed, eight frames per second and 900 pixels wide.
- `progression.png`: G-major accompaniment in the second neck region, following the player clock.
- `uncertain.png`: an unassessed first response, before retrying F→E.
- `studio.png`: the restored practice bookmark.

The banner labels simulated learner actions and input. The capture checks actual playback state, the progression's F/G/final-C sequence, both region diagrams, an unassessed first response, a supported synthetic retry, the local guide and bookmark reload. It does not establish audible quality, hardware latency, fingering, clean technique or learning effectiveness. The later match does not replace the first unassessed response.

`provenance.json` contains media hashes and a bounded evidence summary. The full authored browser evidence remains in the local capture directory. Reproduce with [the capture script](../../../scripts/capture-guitar-homework.ts) and [walkthrough instructions](../../guitar-homework-demo.md). Original art provenance is in [the asset manifest](../../../public/art/provenance.md).
