# Release gates

This repository implements a local-first beta and its optional coaching infrastructure. The following evidence must be collected before claiming the broader product milestones are complete.

| Gate                                | Current evidence                                                                                                                                               | Remaining work                                                                                                                                                                               |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Musical model and measured notation | Original fixtures, deterministic theory tests, SVG layout and painted-label checks, real worker serialization                                                  | Licensed GP3/4/5/GPX corpus and broader technique/engraving review; see fixture inventory                                                                                                    |
| Local player                        | Desktop and mobile Chromium automation, import/persistence, audio transport startup, repeat timeline tests                                                     | Physical Safari/iOS and Chromium/Android audio unlock, latency, interruption, and resume checks                                                                                              |
| Learning                            | Deterministic answer sets, masking, immutable evidence, review and transfer tests                                                                              | Observed learner usability and controlled delayed/transfer assessment                                                                                                                        |
| Forge arrangements                  | Actual bounded inference, verified Agent Lens and Weave records; strict validation; 46/64 fresh requests correct with zero accepted musical/factual invalidity | The 90% request-correctness gate failed. Live arrangement proposals remain disabled by default; hosted operations remain unverified.                                                         |
| Music-teaching agent                | Three local learning areas, derived questions, shared workspace, actor/critic service, and verified live Forge qualification records                           | Actors and judges failed qualification. Cloud teaching stays disabled; held-out teaching-quality evaluation remains unexecuted. See [teacher results](../research/teacher-agent/results.md). |
| Deployment                          | OCI/Render configuration, migrations, recovery scripts, isolated Postgres restore rehearsal                                                                    | Production secrets, managed backups, restore rehearsal in target environment, release rollback exercise                                                                                      |
| Recorded-choice ranking             | GuitarSet blocked holdouts passed the frozen ranking gate; downloaded CV and runtime artifacts reproduce predictions; optional one-change candidate audition   | The UI uses a smaller candidate bank than the offline study. This does not establish comfort, autonomous progression quality, or learning improvement.                                       |
| Learner adaptation                  | Versioned deterministic scheduler; consent-gated recall-prediction pipeline remains separate                                                                   | Real consented attempts and a prospective teaching-policy comparison; no learned instruction policy is promoted.                                                                             |

Do not infer audio quality from a moving cursor, Forge availability from a configured key, or better teaching from a prediction metric. Preserve failed examples as regression fixtures when resolving these gates.

The progression implementation adds confirmed extended harmony, immutable accompaniment variations, source/melody validation, mobile controls, and saved-variation migration. The [arrangement experiment](../research/arrangement-agent/results.md) and [voicing study](../research/voicing-ranking/results.md) own their frozen protocols and service readback. A successful recorded proposal is available as an explicitly labeled local replay; it does not enable live cloud access.
