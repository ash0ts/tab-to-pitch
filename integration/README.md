TabToPitch is consolidated in the private `ash0ts/tab-to-pitch` repository. `main` is the integration branch. The source worktrees remain intact; no personal score, recording, dataset, model weight, credential, dependency directory or generated build belongs in this import.

The adjacent source manifests record file hashes and exclusions. Earlier per-layer verification records describe checks at those layers; they are not a combined release result. [Release verification](release-verification.md) records the integrated checks.

The [historical evidence inventory](historical-evidence.md) records hashes for local artifacts referenced by earlier reports. Those raw files remain in the original archive; a clean checkout includes the reports and access-controlled dashboard links, not datasets, model weights or unrestricted traces.

Overlapping shell, lesson, teacher and player files were reconciled by behavior. The studio does not replace the later CAGED planner, live lifecycle or Ear Lab authority rules. The measured alphaTab patch includes render-revision checks so old worker output cannot update a newer score.

## Shared owners and compatibility

`useLessonSession` persists lesson checkpoints and immutable events. Homework coordinates and playing steps share an assignment. Live attempts remain the source of detected outcomes; homework and stage records reference evidence instead of copying success histories. The progression controller owns selection and derived arrangements. The player and playback coordinator own accompaniment; live capture coexists with them and produces no monitored output.

[Teacher-v5](../docs/teacher-compatibility.md) negotiates the integrated capabilities. Historical teacher-v3 payloads are distinguished by validated capability shape; an ambiguous combination is rejected. Backup fixtures were serialized and validated with each frozen source schema using authored data. Older tasks without the later variant identity remain readable but paused, with exposure unknown.

## Defaults and remaining qualification

Local teaching and unplugged homework work without credentials. Invited cloud teaching has separate enablement and qualification controls. Live detection is experimental, timing stays ungraded, Ear Lab is optional, and Toraneko remains available until its migration gate passes. Failed research candidates are not promoted. Commercial-song annotations awaiting review remain unavailable for grading.

The integration makes no learning-effectiveness claim. Physical Mac/Chrome USB testing, perceptual audio checks and a consented learner study require evidence beyond automated browser fixtures.
