
## Guitar homework integration

The new `homework-playing-v1` layer uses the existing lesson checkpoint and immutable events. Its local music and behavior suites cover single-pitch alternatives, unordered fragments, exact F→E movement, source-preserving progression playback, capability negotiation and invalid actions. The original CAGED coordinate workflow remains separately reachable.

The new isolated-browser suite passed eight desktop/mobile checks covering unplugged reports, optional synthetic input through the real worklet/worker, uncertainty, assistance before teacher exposure, response-method changes and reload interruption. Synthetic input does not qualify hardware or detection accuracy. Production build and type checking pass; final combined CI is recorded in the release receipt rather than inferred from these checks.
