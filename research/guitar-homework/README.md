# Guitar homework behavior evaluation

`guitar-homework-v1` freezes eight authored boundary contexts in `cases.ts`. They cover stopping quizzes, changing goals, correct notes with incorrect roles, unsupported fingering claims, uncertainty, useful retries, help during an attempt, and stale steps. `contract.test.ts` runs the local policy through the same action and reference validators used by the application.

This is an integration check, not an educational study. Cloud actor and critic arms remain **unexecuted**. No new inference, training run, Lens trace, Weave score or dashboard receipt is claimed. Preserve the existing campaign artifacts.
